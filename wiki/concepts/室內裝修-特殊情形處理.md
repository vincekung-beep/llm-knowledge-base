# 室內裝修-特殊情形處理

## 摘要
新北市簡易室內裝修申請中，部分特殊情形需額外備齊專屬文件，包括：套房裝修需取得直下層同意書並附結構計算資料、高層建築需說明燃氣設備合規情形、涉及防火避難綜合檢討建案需進行符合性簽證，這些情形均以「△」符號標示，視個案是否適用而定。

## 詳細說明

### 一、套房裝修（直下層同意書）

**適用情形**：室內裝修涉及增加廁所或浴室及居室，形成多間套房者。

**依據**：「新北市政府辦理建築物裝修為多間套房審查原則」

#### 直下層同意書

直下層同意書需由**申請範圍直下層建築物所有權人**出具，確認同意上方樓層進行套房裝修。

**重要規定：**
- 同意書中需填明增加的廁所或浴室間數、居室間數及套房總數（**不得塗改**）
- 直下層所有權人需**親自簽名及用印**
- 同意書簽署後，室內裝修申請人即可向新北市政府工務局提出申請
- 因簽署本同意書所生之爭議，屬申請人與同意書人間之私權爭執，應由當事人自行調解或另尋司法途徑解決

**免附條件**：直下層所有權人與申請人為同一人者，得免檢附本同意書。

#### 套房裝修應備文件組合（三件套）

施工許可及竣工階段均需（△）：
1. **直下層同意書**：須附直下層第一類登記簿謄本（掛號日前3個月內）及測量成果圖正本
2. **結構計算資料**：結構簽證人員簽名及用印；竣工階段已於施工許可時檢附且未涉及變更者，可免附
3. **損鄰事件處理程序切結書**：申請人及設計建築師均需簽名及用印

#### 直下層同意書份數注意

施工許可申請階段雖僅需準備1份，但建議預先準備**至少乙式3份**（施工許可╱一定規模免變╱竣工），避免日後申辦竣工時產生產權同意爭議。

---

### 二、高層建築物（燃氣設備說明書）

**適用情形**：申請建築物屬高層建築物者。

高層建築物需額外提交兩份文件（施工許可及竣工均需△）：

#### 燃氣設備說明書（建築師出具）

由建築師依建築師法第17條規定查明使照，就下列事項進行審查並說明：

| 審查項目 | 情形 |
|---------|------|
| 未涉及使用燃氣設備 | 於圖說標示，竣工時檢附無使用燃氣設備照片 |
| 涉及使用燃氣設備 | 經檢討符合建築技術規則設備編第四章燃燒設備相關規定 |
| 防火避難審查情形 | 說明本案未涉及/已涉及防火避難綜合檢討或建築物防火避難性能審查 |

說明書須由**建築師事務所及建築師簽章**，若有不實願依建築師法第46條規定接受懲戒處分。

#### 燃氣設備切結書（申請人出具）

申請人切結不得有未經核准之燃氣設備與原核定使用不合之變更等行為，且須列入**產權移轉交代善盡告知之義務**。

---

### 三、防火避難綜合檢討（原認可案件）

**適用情形**：建築物原已取得「防火避難綜合檢討報告書」或「建築物防火避難性能設計畫書」認可者。

申請室內裝修時需就防火避難文件進行符合性檢討，三種情形**擇一**檢附：

#### 情形一：無涉及原認可防火避難文件之說明
- 由建築師出具說明，確認本次裝修**未涉及**原認可防火避難綜合檢討報告書或建築物防火避難性能設計畫書
- 本表應由**建築師簽章**
- 性能設計之案件，應落實確認室內裝修符合驗證所列基本條件（且不能涉及變更驗證條件，如隔間變更）

#### 情形二：原認可之防火避難綜合檢討報告書簽證表
簽證表核查8項指標，確認本次裝修未涉及應重新評定及認可事項：

| 查核項目 |
|---------|
| 1. 未涉及防火區劃變更 |
| 2. 未涉及排煙區劃變更 |
| 3. 裝修變更後天花（平均）高度符合原驗證高度標準 |
| 4. （最遠直角）步行距離不大於原驗證標準 |
| 5. 新增材料耐燃等級不低於原驗證耐燃標準 |
| 6. 避難路徑所經過之出入口符合原報告書或計畫書之標準 |
| 7. 如涉室內裝修行為或牆體變更，天花板下80公分排煙之開口面積不小於防煙區劃樓地板面積2%，且該開口應開設於外牆或與排煙風道（管）相接，且變更後排煙效能確認未低於原驗證排煙效能 |
| 8. 其餘變更項目皆符合原報告書或計畫書標準 |

總結：經檢討本次變更未涉及原認可報告書內所載明應重新申請評定及附錄驗證條件之事項。本表應由**建築師（設計人）簽章**。

#### 情形三：檢附變更後防火避難綜合檢討報告書或建築物防火避難性能設計畫書
- 檢附**正本**
- 應由建築師確認內容是否與申請案相符，如有不符應再檢附上項簽證說明書或簽證表

---

### 四、先行動工（施工許可申請前已施工）

**適用情形**：申請施工許可證前已先行動工者。

需擇一檢附（施工許可申請項次9-6）：
1. **拆改切結書**：申請人簽章
2. **罰款切結書**：申請人簽章
3. **罰款繳納證明**：正本或影本（採影本者用印加蓋相符章）

---

### 五、併案申請一定規模免變

**適用情形**：室內裝修同時涉及一定規模以下免辦理變更使用執照事項（用途或構造）者。

**重要限制**：
- 免變（用途）：須於申請施工許可證**前**先完成核准，核准文號填入申請書
- 免變（構造）：雖可與室內裝修案件一起申請，但取得施工許可證後，免變項目尚未經市府核備完竣前**不得施工**；若先行動工衍生爭端，概由簽章人員負責
