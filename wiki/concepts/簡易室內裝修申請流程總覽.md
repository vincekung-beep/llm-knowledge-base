# 簡易室內裝修申請流程總覽

## 摘要
新北市簡易室內裝修申請分為兩大階段：先向審查機構申請「施工許可證」取得核准後方可施工，施工完成後再申請「竣工審查」取得合格證明，整個流程需備齊特定文件並由建築師或室內裝修業者簽章負責。

## 詳細說明

### 整體流程概覽

```
準備文件 → 申請施工許可證（向審查機構掛件）→ 取得核准 → 依圖施工
→ 施工完成 → 申請竣工審查（繳回施工許可證正本）→ 取得合格證明
```

### 第一階段：施工許可證申請

申請人須備妥規定文件，向新北市核准之室內裝修審查機構提出申請。審查機構審查通過後，核發施工許可證（乙式2份，1份留存審查機構，1份核准後檢還申請人）。

**關鍵注意事項：**
- 所有文件用印、簽名格式應一致
- 涉及一定規模免變（用途）者，應於申請施工許可證前先辦完核准
- 涉及併案申請一定規模免變（構造）者，取得施工許可證後仍不得施作免變部分，需等市府核備完竣

### 第二階段：竣工審查申請

施工完成後，申請人須將施工許可證正本繳回，並備妥竣工審查文件向審查機構提出申請。審查機構審查通過後，核發室內裝修合格證明。

**關鍵注意事項：**
- 施工許可證正本需繳回，不得塗改；如遺失應登報作廢後附影本
- 確認施工許可證工期是否仍有效，逾期應檢附展延證明
- 竣工照片每一空間至少應檢附雙向彩色照片

### 兩階段應備文件比較

| 文件類別 | 施工許可階段 | 竣工審查階段 |
|---------|------------|------------|
| 審查/查驗核審表 | 新北市建築物簡易室內裝修施工許可簽章合格審核表 | 新北市建築物簡易室內裝修竣工查驗簽章合格審核表 |
| 申請書 | 新北市簡易室內裝修施工許可證申請書 | 新北市建築物室內裝修合格證明申請書（或住宅版） |
| 許可證/圖說 | 新北市簡易室內裝修施工許可證（乙式2份） | 繳回施工許可證正本（含圖）；檢附竣工圖說 |
| 裝修圖說 | 裝修平面圖、天花平面圖 | 竣工圖說（含原使照竣工圖說，◎可免附） |
| 送件人員名單 | 申請建築執照送件審圖手續人員名單 | 室內裝修送件審圖手續人員名單 |
| 違建文件 | 違建項目簽證表＋違建索引圖面及相片 | 違建項目簽證表暨違建相片（含示意圖） |
| 建物產權文件 | 第一類建物謄本、測量成果圖、建築物使用權同意書 | ◎若已於施工許可提交且未變更，可免附 |
| 使照文件 | 使照、變使、室裝等存根或用途免變證明文件 | ◎原使用執照影本（已附者免附） |
| 變更記錄 | 變更記錄切結書 | 變更記錄切結書＋（△）併竣工修正說明書 |
| 高層建築 | △燃氣設備說明書＋切結書 | △燃氣設備說明書＋切結書 |
| 套房裝修 | △直下層同意書＋結構計算資料＋損鄰切結書 | △直下層同意書＋結構計算資料＋損鄰切結書 |
| 防火綜檢 | △防火避難綜合檢討相關文件 | △防火避難綜合檢討相關文件 |
| 竣工專屬文件 | — | 竣工材料書、綠建材評估總表、竣工照片、材料證明、施工證明書等 |

> **符號說明：**
> - ◎ 已於施工許可階段檢附且內容未變更者，竣工階段免附
> - △ 視個案情形依法令規定需要時才需檢附

### 申請書版本說明

竣工申請書分為兩版，擇一使用：
- **一般版**（`新北市建築物室內裝修合格證明申請書`）：一般建築物適用，需附竣工查驗簽證檢查表、竣工材料書、施工證明書等
- **住宅版**（`新北市住宅及集合住宅建築物室內裝修合格證明申請書`）：住宅及集合住宅適用，免附竣工查驗簽證檢查表、竣工材料書、施工證明書、室內裝修施工業者聘任切結書
